# CLIVE

CLIVE is George's business assistant for CROOKS LDN. It runs on one server and is used on his tablet, his phone, the studio TVs and the team's phones.

What it does:
- It hears what he says and answers out loud.
- It reads the Shopify shop, Gmail, Instagram and Ship24 tracking.
- It prepares changes to the shop and the inbox. Nothing happens until someone confirms the change on its card.
- It keeps his objectives and puts things on the TVs.
- It gives each member of the team their own CLIVE at `/today`.

It started on 7 September 2026 as a read-only voice assistant on one tablet.

This folder holds the app:
- a FastAPI backend in `app/`;
- a web front end in `web/`, plain JavaScript with no build step;
- the tests, the scripts, the deploy files and the product memory.

## Run the tests

You need Python 3.11 or newer (CI uses 3.12), and Node for the web tests.

```bash
make venv                                                    # once: .venv with the app and its dev tools
.venv/bin/pytest tests/test_<area>.py -q -p no:cacheprovider   # the tests for what you changed
make lint                                                    # ruff over app, config, scripts and tests
.venv/bin/python scripts/product_memory_check.py             # the product memory's structure
.venv/bin/python scripts/map.py --check                      # MAP.md's tables still match the code
```

- **The full suite** (`make test`, offline) is what GitHub's `acceptance` workflow runs on every pushed SHA (`.github/workflows/acceptance.yml`, then `scripts/acceptance_provenance.py`). On a small machine, push your branch and read that run rather than running everything locally.
- **Live tests** are marked `live`, need real credentials, and are left out by default.
- **Web unit tests** (`tests/web/*.test.js`) run under Node through `tests/test_web_js.py`.
- **Browser checks** are `scripts/browser/*.js`, using Playwright and Chromium. GitHub installs no browser, so the browser-backed tests skip there.

## Deploy

- **Where production runs:** the server `crooks-os-prod-1`, in `/opt/crooks-os`, under the systemd service `crooks-assistant.service`. It is reachable only over Tailscale.
- **How to install, configure, deploy and roll back:** [`docs/DEPLOY_LINUX.md`](docs/DEPLOY_LINUX.md).
- **Where deploys come from:** only `clive/trunk`. Each one leaves a record in [`reports/`](reports/) as `deploy-<sha>.md`.
- **What stays out of this repository:** the production `.env` and every secret. They are the owner's.
