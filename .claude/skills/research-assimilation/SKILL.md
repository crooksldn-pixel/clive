# Research Assimilation

For every external source:
1. resolve canonical upstream;
2. pin exact commit/version;
3. record license;
4. inspect install scripts, hooks, binaries, symlinks and agent instructions;
5. inventory useful parts;
6. compare with current CLIVE;
7. classify adopt / park / reject;
8. rebuild or import only the bounded useful pattern;
9. define a measurement proving improvement;
10. drop it if it does not improve results.

Never wholesale-install an agent framework because it is popular.
