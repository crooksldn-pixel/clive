# CLIVE UI

For Builds/project surfaces, default information is:
- project name;
- meaningful state;
- trustworthy progress;
- what needs George now.

Hide until requested:
- SHAs;
- worker ids;
- token/model trivia;
- raw logs;
- internal state-machine details.

Do not create dashboards for the sake of activity. Reuse existing CLIVE design/components where possible. Test meaningful interaction changes on phone and tablet sizes in real Chromium.
