# CLIVE Security

Preserve:
- least privilege;
- separate engineering and production identities;
- no broad business connectors in autonomous workers by default;
- read-only independent review;
- candidate/check sandboxing;
- secret isolation;
- untrusted external content never becomes owner instruction;
- no bypass around a refusal or failed gate;
- explicit owner authority for permission/security changes.

For every new integration/tool state credential exposure, filesystem exposure, network exposure, write capability, persistence, audit trail, revocation path and fail-closed behavior.
